A SMALL GUIDE TO PRECISE RESULTS

From structures to reference energies.

Prepare two files, choose your calculation, and download a complete .ref.

01 · Prepare your input

Try the bundled H₂ example: download the geometry archive ↓ and reference template ↓. Load the example files to start a new task. You can also select a .ref together with your geometry archive, or add one after choosing the archive.

Upload a .tgz or .tar.gz containing .xyz geometries. Add a .ref template for reaction energies, or omit it to calculate each structure’s total energy. Geometry names must be unique across the archive; use filename stems in the reference.

# water.xyz
3
0 1
O  0.000  0.000  0.000
H  0.758  0.000  0.504
H -0.758  0.000  0.504

The first line is the atom count. The second is charge multiplicity (here neutral, singlet). Coordinates are in ångström.

# coefficient molecule [coefficient molecule ...] reference ratio
-1 reactant 1 product ? 1
1 water ? 1

Use ? for missing reference energies. A numeric reference is recomputed. A completely empty .ref produces one row per structure. With a trailing ratio, reference values are the weighted sum of molecular energies in kcal/mol; the ratio is preserved as DFThub metadata and does not divide the energy. Without a ratio, reference values remain in hartree.

02 · Choose your theory

CCSD iterates singles and doubles; CCSD(T) adds perturbative triples. CCSDT iterates triples, and CCSDT(Q) adds the perturbative quadruples correction. All calculations use canonical coupled cluster and correlate all electrons.

Available methods are detected from the configured PySCF interpreter. In PySCF 2.14, CCSDT(Q) supports closed-shell structures; open-shell CCSDT(Q) is unavailable. The interface reports the installed environment’s actual support.

3ζ, 4ζ, and 5ζ use cc-pVTZ, cc-pVQZ, and cc-pV5Z. Choose aug-cc-pVnZ to include diffuse functions. CBS computes the selected 3ζ/4ζ or 4ζ/5ζ pair and extrapolates correlation energy with X⁻³ and Hartree–Fock energy with exp(−1.63X). The calculation report retains both basis components. Unsupported elements fail explicitly.

03 · Allocate resources

Thread pool size is the job’s CPU-thread budget. Threads per task controls each PySCF calculation. Concurrency is floor(pool threads ÷ threads per structure); any remainder stays idle. With parallel execution off, one structure uses the whole thread pool.

Memory pool size is displayed in GB and divided by concurrent structures. Energyhub converts this to MB for the calculation API. Jobs share server-wide CPU thread, calculation slot, and memory pools, and wait when resources are occupied. Open resource settings in the navigation to change server limits when the queue is idle.

04 · Follow your calculation

Open a task to see measured progress, errors, resource allocation, and molecular energies. Progress counts completed structures, so a single expensive structure may remain at 0% for a while. The page can be closed and reopened while the server continues calculating.

Stop task terminates the calculation and its workers. Download becomes available only when every required structure has converged and the complete .ref has been written. Reports include PySCF version, reference type, corrections and CBS components. Task history persists across server restarts; interrupted tasks are marked failed.
